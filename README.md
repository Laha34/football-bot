# ⚽ Football Reminder Bot — Man City & Barcelona

Telegram-бот, який стежить за матчами Манчестер Сіті та Барселони і надсилає
нагадування: вранці в день матчу та за годину до початку.

## Що всередині

- `bot.py` — головний файл, запускає бота
- `football_api.py` — запити до football-data.org
- `reminders.py` — логіка "чи час надіслати нагадування"
- `db.py` — маленька SQLite база, щоб не дублювати нагадування
- `config.py` — зчитує налаштування з `.env`
- `.env.example` — шаблон файлу з ключами доступу

## Крок 1. Встанови Python-залежності

Відкрий термінал у папці проєкту і виконай:

```bash
pip install -r requirements.txt
```

Якщо це перший раз, коли ти працюєш з Python-проєктами, рекомендую спершу
створити віртуальне середовище (не обов'язково, але охайніше):

```bash
python3 -m venv venv
source venv/bin/activate   # на Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Крок 2. Налаштуй ключі доступу

1. Скопіюй `.env.example` в новий файл `.env`:

   ```bash
   cp .env.example .env
   ```

2. Відкрий `.env` у будь-якому текстовому редакторі і встав свої значення:
   - `BOT_TOKEN` — токен від @BotFather
   - `FOOTBALL_API_KEY` — токен з football-data.org
   - `CHAT_ID` — твій ID від @userinfobot

   `TEAM_IDS=65,81` можна не чіпати — це вже Manchester City і Barcelona.

## Крок 3. Запусти бота

```bash
python3 bot.py
```

Якщо все налаштовано правильно, у терміналі з'явиться:
```
Бот запущено. Натисни Ctrl+C, щоб зупинити.
```

Тепер відкрий свого бота в Telegram і напиши `/start`, а потім `/matches`,
щоб перевірити, що він бачить розклад.

## Як це працює

- Кожні 5 хвилин бот запитує в football-data.org найближчі 2 дні матчів
  обох команд.
- Якщо сьогодні день матчу і настала 9:00 (можна змінити в `.env`) —
  надсилається ранкове нагадування.
- Якщо до матчу лишилось ~1 година — надсилається друге нагадування.
- SQLite-база (`bot.db`, створюється автоматично) запам'ятовує, які
  нагадування вже надіслані, щоб не дублювати їх.

## Поширені проблеми

**"У файлі .env не заповнено..."**
Значить, один з ключів у `.env` порожній або файл не скопійований з `.env.example`.

**Бот не відповідає на команди**
Перевір, що BOT_TOKEN скопійований повністю, без зайвих пробілів.

**"Не вдалося отримати дані з football-data.org"**
Перевір FOOTBALL_API_KEY. Також безкоштовний тариф має ліміт 10 запитів/хв —
для двох команд цього достатньо, але якщо тестуєш дуже часто, можеш його вичерпати.

## Наступні кроки (коли захочеш розвивати далі)

- Задеплоїти бота на сервер (Railway, Render, звичайний VPS), щоб він працював 24/7,
  а не тільки поки запущений у тебе на комп'ютері
- Додати команду для додавання/видалення команд без редагування `.env`
- Підтримка кількох користувачів (зараз бот "персональний" — шле лише на один CHAT_ID)
